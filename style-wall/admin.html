設定（每台裝置貼一次）

金鑰只存在這台瀏覽器的 localStorage，不會上傳，也不會寫進 GitHub。換瀏覽器或清掉網站資料後要再貼一次。不要在共用電腦上儲存。

GitHub 細粒度 token
  1. 打開 建立細粒度 token。
  2. 名稱可填 style-wall。Repository access 選 Only select repositories，只勾 style-wall。
  3. Permissions → Contents 設成 Read and write。其他權限不要開。
  4. 產生後立刻複製，貼到下面。token 只顯示一次。
Gemini API 金鑰
  1. 打開 Google AI Studio 金鑰頁。
  2. 建立 API key，複製後貼到下面。
  3. 預設模型是 gemini-4-hydrogen，能看圖與影片。gemini-2.5-flash 將在 2026-12-01 被轉走，不建議再填。
